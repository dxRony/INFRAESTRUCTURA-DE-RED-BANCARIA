########## NAT
  ip nat inside source list 100 interface Gi0/0 overload   (Internet: 172.16/16)
  ip nat inside source list 101 interface Gi0/1 overload   (B2: 172.16/16)
  ip nat inside source static tcp 172.16.30.5 80  interface Gi0/1 80
  ip nat inside source static tcp 172.16.30.6 8080 10.0.0.1 8080 extendable
  ip nat inside source static tcp 172.16.30.6 8080 10.0.0.18 8080 extendable

  access-list 101: permit 172.16.0.0/16 any

########## SLA / TRACK (monitoreo del anillo)
  ip sla 1 icmp-echo 10.0.0.2           freq 5  (B1-B2)
  ip sla 2 icmp-echo 10.0.0.6  src Gi0/1 freq 5  (B2-B3)
  ip sla 3 icmp-echo 10.0.0.10          freq 5  (B3-B4)
  ip sla 4 icmp-echo 10.0.0.17          freq 5  (B1-B5)
  ip sla 5 icmp-echo 10.0.0.13 src Gi0/2 freq 5  (B4-B5)
  todos schedule life forever now
  track 1/2 : line-protocol de Gi0/1 y Gi0/2
  track 3-7 : ip sla 1-5 reachability (delay down 10 up 5)
  track 10 = ip sla 2 ; track 20 = ip sla 5

########## POLICY ROUTING LOCAL
  ACL-SLA-B2-B3: permit icmp host 10.0.0.1 host 10.0.0.6
  ACL-SLA-B5-B4: permit icmp host 10.0.0.18 host 10.0.0.13
  route-map RM-LOCAL-SLA permit 10: match ACL-SLA-B2-B3 ; set ip next-hop 10.0.0.2
  route-map RM-LOCAL-SLA permit 20: match ACL-SLA-B5-B4 ; set ip next-hop 10.0.0.17
  ip local policy route-map RM-LOCAL-SLA
