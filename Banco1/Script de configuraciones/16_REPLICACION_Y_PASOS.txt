 PASO 1 - SWITCHES (capa 2)
-------------------------------------------------------------------------------
  switch-sede-central:
    vlan 10 / name CAJA_SEDE
    vlan 20 / name ADMIN_SEDE
    vlan 30 / name SERVIDORES_SEDE
    int Gi0/1 -> switchport access vlan 10
    int Gi0/2 -> switchport access vlan 20
    int Gi0/0, Gi0/3 -> switchport access vlan 30
    int Gi1/2 -> access vlan 30 (si se usa)
    int Gi1/3, Gi2/0..  -> default vlan 1
    TRUNK hacia routers: Gig0/<trunk> switchport mode trunk
        switchport trunk allowed vlan 10,20,30
    interface Vlan20: ip address 172.16.20.10 255.255.255.0 (mgmt)
  switch-sucursal-1:
    vlan 40 / name CAJA_SUCURSAL ; vlan 50 / name ADMIN_SUCURSAL
    int Gi0/2 -> access vlan 40 (caja-suc)
    int Gi0/1 -> access vlan 50 (admin-suc)
    interface Vlan50: ip address 172.16.50.10 255.255.255.0 (mgmt)

 PASO 2 - ROUTER-1-SEDE-CENTRAL (activo principal)
-------------------------------------------------------------------------------
  Los comandos aqui son el contenido exacto del archivo 01_Router-1-sede-central.txt.
  Destacados:
    int Gi0/0.10 ; encapsulation dot1Q 10 ; ip addr 172.16.10.2/28
        ip access-group ACL_CAJA_SEDE in ; CAJA_OUT out
        standby 10 ip 172.16.10.1 ; standby 10 priority 110 ; standby 10 preempt
    int Gi0/0.20 ; encap 20 ; ip addr 172.16.20.2/24
        ip access-group SSH-L3-SEDE out
        standby 20 ip 172.16.20.1 ; prio 110 ; preempt
    int Gi0/0.30 ; encap 30 ; ip addr 172.16.30.2/29
        ip access-group ACL_SERVERS_SEDE in ; SERVERS_OUT out
        standby 30 ip 172.16.30.1 ; prio 110 ; preempt
    int Gi0/1: ip addr 10.10.0.1/30
    int Gi0/2: ip addr 172.16.0.1/30
    Rutas: (ver 15_ACLs_Rutas_NAT_referencia.txt)
      ip route 10.0.0.0/30 172.16.0.2, 10.0.0.4/30, 10.0.0.8/30,
              10.0.0.12/30, 10.0.0.16/30 (via 172.16.0.2)
      ip route 10.10.1.0/30 172.16.10.3
      ip route 172.16.40.0/28 10.10.0.2, 172.16.50.0/24 10.10.0.2
      ip route 0.0.0.0/0 172.16.0.2 (default)
    HSRP: standby 10 ip 172.16.10.1 prio 110 preempt
          standby 20 ip 172.16.20.1 prio 110 preempt
          standby 30 ip 172.16.30.1 prio 110 preempt
    write memory

 PASO 6 - FIREWALL-SEDE-CENTRAL (docker)
-------------------------------------------------------------------------------
  Config = Cmd del contenedor (archivo 07_Firewall-sede-central.txt seccion 1).
  En GNS3 el nodo docker se monta con ese Cmd; respuesta replicable:
    - Interfaces: eth0 172.16.0.2/30, eth1 172.16.1.2/30, eth2 10.10.2.2/30
    - Rutas vivas:
        default via 10.10.2.1 (Router-salida)
        172.16.0.0/16 via 172.16.0.1 (R1) y via 172.16.1.1 (R2) metric 20
        + RETORNO DNS agregado: 10.10.0.0/30 via 172.16.0.1 dev eth0
          y 10.10.1.0/30 via 172.16.1.1 dev eth1
    - iptables: policies DROP; DNS REDIRECT 53 en eth0/eth1;
      DNAT 80->172.16.30.5, 8080->172.16.30.6; raw bloqueo B3/B4.
    - dnsmasq BLACKLIST (ver seccion 3 del 07_): facebook.com, tiktok.com,
      instagram.com, dominio.com (www. incluidos) --> 127.0.0.1 y ::1
    - socat: 172.16.0.2:80->172.16.30.5:80 ; 172.16.1.2:80->web ;
      0.0.0.0:8080->172.16.30.6:8080
  IMPORTANTE para persistencia: en docker GNS3 el Cmd SI aplica (startup_command
  en API =0; la config real la guarda el contenedor). Backupear
  project-files/docker/19e41051-.../startup_cmd.sh.
